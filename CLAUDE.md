# CLAUDE.md: Enamel

The issuer studio behind Sash: design a badge or a certificate with a parametric
editor, save versions, publish, and hand it out with claim links that expire.
For somebody who wants to award something to other people and does not want to
open a drawing tool to do it.

**Live:** enamel.neorgon.com · **Port:** 8885

## Run

```bash
make serve
```

Then open http://localhost:8885. It must be served over HTTP, because the app is ES modules and `file://` blocks them.

## The backend is somebody else's folder

**There is no `convex/` here, and there is not meant to be.** Enamel points a
`ConvexHttpClient` at Sash's deployment and calls the same functions:
`projects/sash-site/convex/` is the only `convex/` folder in this campaign, and
`projects/sash-site/convex/README.md` is where the server side is documented.
Nothing else in the fleet does this, so the next operator will look for
`enamel-site/convex/` and not find it. CONTRACTS.md C8.1.

Sash owns the folder because Sash is the system of record: it holds `profiles`,
`awards`, `claims` and `kudos`, and it is the origin printed on every artefact.
Enamel writes `templates` and `templateVersions` and nothing else.

The deployment URL is a `<meta name="neo-convex-url">` on every page rather than
a constant in a JS file, so checking that the two sites agree is a `grep` and
swapping dev for production is one change per page. The production deployment is
`youthful-oyster-436`, and all four pages name it. `js/convex.js` reads it and
**throws on load** if it is absent or malformed, which is deliberate: a page with
no deployment is not a page that should half work.

## Data

- `localStorage['enamel-studio-v1']`: the working draft, one design per kind,
  plus the metadata and the id of the template on Sash. It is a convenience for
  a refresh; the template row is the record.

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines, and `js/app.js` under 50. It currently holds
  for every file this site owns; the vendored kits are not this site's count.
- Sign-in is the Neorgon Auth Kit: `js/neorgon-auth.js`, `js/neorgon-auth-sites.js`
  and `css/neorgon-auth.css`, synced by `packages/neorgon-ui/sync-auth.sh`. It
  owns the header slot, the sign-in dialog and the Convex token. `js/auth.js`
  only listens, and the pages call `NeoAuth.requireSignIn` in front of a write.
  The site-local sign-in sheet, its `.auth-*` CSS and `js/vendor/` are gone; do
  not bring any of them back, and never style `.neo-auth` here.
- No inline `onclick` anywhere, and nothing exposed on `window` for one. The
  editor wires one delegated listener per root and reads `data-path`.
- The only local identity knob is `--accent` (`#f97316`) and the `--accent-bright`
  that pairs with it. Every other token comes from the CDN `base.css`.

## Gotchas

**A production Clerk key does not work on localhost.** The key on every page is
the fleet's production instance, and Clerk refuses it on any origin that is not
`neorgon.com`: the console says "Production Keys are only allowed for domain
neorgon.com" and no session is possible. The Auth Kit settles as `unavailable`,
keeps its header slot hidden, answers `requireSignIn` with false, and `js/auth.js`
still hands the page a signed-out session, so every page renders its signed-out
state rather than an error. So `make serve` gives you the editor, the presets,
the warnings, the downloads, the public catalogue and every published-template
read, and nothing that needs an identity. That is not a bug in this site and
there is no local workaround short of a development Clerk instance.

**`js/convex.js`, `js/insignia/*`, `js/neorgon-*.js` and `css/neorgon-*.css`
are not this project's to edit.** The first is written by the backend and
vendored identically into `sash-site`; the rest come from `packages/neorgon-ui/`
and are overwritten by their sync scripts. If one of them is missing something,
fix the canonical source and re-run the sync.

**Do not write `escHtml` here. It exists.** `js/neorgon-dom.js` is the Neorgon
DOM Kit, vendored by `packages/neorgon-ui/sync-dom.sh`, and it owns `escHtml`,
`showToast`, `debounce`, `copyText` and the rest. C15 A53: this site had its own
`escHtml` escaping four characters where the kit's escapes five, no `'`, and
`editor.js` alone interpolates it into forty-odd attributes. Import it from
`./neorgon-dom.js` at the call site, never through `./utils.js`, so there is one
name for it and a second body cannot appear under the old one. `js/utils.js`
keeps `$`, the design-path helpers and the dates. **`$` is not Sash's
`$`**: this one re-resolves when the cached node has left the document, because
the editor rebuilds whole panels; Sash caches permanently because it never
replaces a node. Both are right for their site.

**One date format, and it belongs to the kit.** `formatDate` in
`js/insignia/certificate.js` renders `9 September 2026` and is the only date
formatter either site may use (A54). `js/utils.js` adapts it for the epoch ms
this site holds: `fmtDate` for a day, `stamp` for a day and a UTC time, and
`humanMs` for a duration in words. `humanMs` replaced `describeValidity`, which
agreed with Sash only over the four fixed values `VALIDITY_CHOICES` offers and
rendered anything under twelve hours as "0 years". `stamp` and `humanMs` are
byte-identical to Sash's, and there is no `--check` on that pair, so change one
and change both. A `toLocaleDateString` or a `toLocaleString` anywhere in this
repo is a regression.

**Framing cannot be prevented here, so it is handled instead.** C5.3 froze a
frame buster (`window.top.location = window.self.location`); measured from a
real cross-origin host it is refused for want of user activation in Chromium,
Firefox and WebKit alike, throws, and leaves the page framed. C15 A36 replaced
it. `frame-ancestors` is the directive that would work, it is ignored in a
`<meta>` CSP by specification, and GitHub Pages sets no response headers.

Three pieces, and all three have to be there: the inline guard in the `<head>`
sets `data-framed` on `<html>` and navigates nowhere, `css/frame.css` takes the
page out of view, and `js/frame.js` puts a notice in its place. Every entry
module imports `framed` and returns before it mounts anything, which is what
keeps sign-in and every write control off a framed page. **Do not put the buster
back**, and note that Sash's `embed.html` is the one page in the campaign
without the guard, because being framed is its whole purpose. Enamel has no
embed page, so all four of its pages carry it.

**The kit is the only drawing path.** `renderSvg` throws a `TypeError` without a
valid provenance object, and it draws the provenance strip in preview mode too,
so an author cannot design around a band they have never seen. Do not build an
SVG here. `js/preview.js` hands a design and a provenance to the kit and appends
what comes back.

**The preview passes a placeholder verify URL on purpose.** With an empty one the
kit draws no QR, so a certificate author would lay out around a square up to 400
units across that appears only once an award exists. The strip's own text still
reads "preview, not yet issued": the kit builds that line from the mode, never
from the URL.

**A template's kind is fixed once it exists.** Publish refuses a badge row
holding a certificate design, so switching Badge to Certificate in the studio
detaches from the open template and starts a new design. The other one is
untouched, and the toast says so.

**Choosing "an image" for the centre opens the file picker straight away.** A
centre of kind `image` with no `imageRef` is an invalid C1 document, and the
refusal would otherwise arrive from the deployment on save with nothing on screen
to explain it. Abandoning the upload puts the centre back on a glyph.

**`:not([open])` in a stylesheet matches a `<div>`.** The editor's groups are
`<details class="editor__group">` and the font pairing block used the same class
on a plain `<div>`, so `.editor__group:not([open]) > .editor__body { display:none }`
hid a control that is meant to be visible at all times. The rule is scoped to
`details.editor__group` now. A div can never carry `open`, so `:not([open])`
always matches one.

**The two authoring warnings are graded, not binary.** `js/warnings.js` measures
arc text against the silhouette with `isPointInFill` over 42 sample points, the
same technique and the same count the catalogue was designed with, and it grades
contrast at 3:1 and 4.5:1 rather than one threshold. All twelve badge presets and
eleven of the twelve certificate presets are silent; `graphite` draws a note at
4.4:1, which is a deliberate light-ground design rather than a mistake. A warning
that fires on a shipped preset teaches an author to ignore warnings.

**Nothing here duplicates a server check.** The real-issuer blocklist, the input
caps, the rate limits and every authorisation rule live in the deployment. This
site renders what comes back, and `js/api.js` is the one place that knows an
authentication failure throws while every other failure returns
`{ ok:false, code, message }`.
